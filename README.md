# ebay redirect
ebay.com is a horrible website that i always accidentally 
go to instead of my own ebay.co.uk. In ebay's infinite wisdom, 
these websites aren't always linked despite accounts working 
across them. 

Items to sell made on ebay.com, for example, will be stuck
on ebay.com with US Dollars and US delivery options. There
is currently no way to transfer these items to ebay.co.uk, and
ebay.com does not allow you to change the currency or delivery
options. Even if you access these items from ebay.co.uk.

Thanks eBay!

currently supports firefox only. \
